# Marketing GIFs

Made with [gif-studio](https://github.com/pkarolak/gif-studio). Run `npx gif-studio guide` for the workflow.

Each folder is one asset: `scene.html` (animation source), `brief.md` (copy = script), `notes.json` (review notes), `versions/` (every render), `final/` (shipped GIF + MP4 + stills).
